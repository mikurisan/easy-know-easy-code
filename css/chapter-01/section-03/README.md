*Source: [Basic CSS selectors](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Basic_selectors)*

# 1 What is selector?

用于选取 elements, 被选取的 elements 叫做 *subject of the selector*.

# 2 Type selectors

也叫 *tag name selector* 或 *element selector*.

用于根据 element 名称选择 elements.

# 3 Class selectors

选择 `class` attribute 为指定 value 的 elements.

# 4 ID selectors

选择 `id` attribute 为指定 value 的 elements.

# 5 Selector lists

在 selectors 之间添加 comma 即可并列使用.

# 6 The universal selector

即 asterisk `*`.
